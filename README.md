# Notice: Repository Deprecation

This repository is deprecated and no longer actively maintained. It was built on Google Cloud's Vertex AI **Codey** (`code-bison`) API and the `textembedding-gecko` embeddings model, both of which Google has since retired, and it uses the removed `knnBeta` Atlas Search operator. **The demo will not run as-is.**

This repository remains accessible for reference purposes only. It will not receive further updates, bug fixes, or security patches, and may expose you to security vulnerabilities and compatibility issues. Any use is at your own risk.

For current, maintained examples of generative AI with MongoDB — including RAG, AI agents, and natural language querying — see the [MongoDB GenAI Showcase](https://github.com/mongodb-developer/GenAI-Showcase) and the [MongoDB Developer Center](https://mongodb.com/developer).

---
